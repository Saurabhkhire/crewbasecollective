## `data/` — content source of truth

| Path | Purpose |
|------|---------|
| `companies.json` | All sponsor/partner companies |
| `people.json` | All people (includes private email/phone/notes/roles) |
| `events/{uuid}.json` | One full `EventRecord` per event |
| `settings.json` | Sub-roles, community links, SMTP config, email templates |
| `images/companies/`, `images/covers/`, `images/events/{event-name}/` | Logos, covers, galleries |

## `client/` — public website + admin screens

### Config
| File | Purpose |
|------|---------|
| `vite.config.ts` | Port 5173, `/api` proxy → :4000, `@` alias → `src/`, `spaFallbacks()` plugin writes `index.html` per route/event |
| `tailwind.config.ts`, `postcss.config.js` | Tailwind setup |
| `index.html` | HTML shell |
| `public/` | Static assets: logos, plus 🔧 `data/` and 🔧 `images/` generated by `build:data` |

### `client/src/`
| File | Purpose |
|------|---------|
| `main.tsx` | React entry, wraps `App` in `BrowserRouter` |
| `App.tsx` | Public routes: `/`, `/events`, `/events/:slug`, `/sponsors`, `/people`, `/get-involved` (`/join` redirects), 404 |
| `index.css` | Dark theme CSS variables + shared utility classes |

### `client/src/pages/` (public)
| File | Reads | Purpose |
|------|-------|---------|
| `Home.tsx` | events-index, people, sponsors | Hero, featured events, community stats |
| `Events.tsx` | events-index | Upcoming / past event lists |
| `EventDetail.tsx` | `events/{slug}.json` (falls back to index lookup) | Full event page: schedule, sponsors, partners, prizes, judges, speakers, hosts, photos, links; hides empty sections |
| `Sponsors.tsx` | sponsors | Sponsors, partners, venue & community partners |
| `People.tsx` | people | Directory grouped by involvement (uses `PeopleList`) |
| `GetInvolved.tsx` | community-links | Community links (Discord, WhatsApp, Luma) + the request forms (`RequestForms`) |
| `NotFound.tsx` | — | 404 |

### `client/src/pages/admin/` (CMS screens — rendered by `cms/`)
| File | Purpose |
|------|---------|
| `Layout.tsx` | Admin shell + nav (Events, Sponsors & Partners → Companies, People, Settings) |
| `Events.tsx` | Event list, create, delete, filters |
| `EventDetail.tsx` | Big event editor with tabs: basics, tracks, sponsors, partners, prizes, schedule, speakers, judges, hosts, volunteers, associated, people, links, photos. Talks to `/api/admin/events/:id/detail` |
| `Companies.tsx` | Company CRUD + logo upload + involvement view |
| `People.tsx` | People CRUD, role assignments, filters, Send email |
| `Settings.tsx` | Sub-roles, community links, SMTP, email templates, pitch-deck upload |

### `client/src/components/`
| File | Purpose |

### `client/src/components/admin/`
| File | Purpose |
|------|---------|
| `SendEmailModal.tsx` | Compose/preview/send invite, certificate, sponsorship emails |

| `SortableList.tsx` | Drag-and-drop reorder |

| `SubRoleMultiSelect.tsx` | Sub-role chips |

### `client/src/lib/`
| File | Purpose |
|------|---------|
| `api.ts` | `api()` — JSON fetch for `/api/*`; `loadData()` — no-cache fetch for `/data/*.json` |
| `upload.ts` | Client helpers for CMS upload endpoints |
| `utils.ts` | `cn()`, local-date parsing/formatting, past/upcoming split, enum label maps |
| `roles.ts` | Fixed roles, sub-role helpers (client copy of server logic) |
| `event-people.ts` | Aggregates all of an event's role rows into one row per person (admin People tab) |
| `event-links.ts` | Normalize Luma/Eventbrite links (array or legacy single field) |

### `client/api/` — ⚪/fallback Vercel functions
`health.ts`, `subscribe.ts`, `requests.ts`: self-contained copies of the forms API, only used if Vercel Root Directory = `client/`. Keep in sync with `server/src/routes/forms.ts`.

`aim-hack-chat.ts`: OpenAI endpoint for the separate `/aim-hack-visual` site in `client/public/aim-hack-visual/` (see [AIM_HACK_VISUAL.md](AIM_HACK_VISUAL.md)). No `client/vercel.json` — adding one broke the deploy.
