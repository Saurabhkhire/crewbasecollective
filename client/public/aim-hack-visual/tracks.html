⚠️ Common pitfalls

These are the traps that turn a multiplayer-agent project into "just another chatbot."

ALL TRACKS

A chatbot with a face

✕ One assistant with an avatar answering questions.
✓ 3+ agents with their own goals who talk to each other, not just to you.
ALL TRACKS

Secretly scripted

✕ A hard-coded plot that the agents just narrate.
✓ Real choices with real consequences. Run it twice to prove the outcome changes.
ALL TRACKS

Text-only agents

✕ Agents whose decisions only show up as chat messages.
✓ Every decision becomes movement or action on screen.
ALL TRACKS

Invisible reasoning

✕ Things happen and nobody knows why.
✓ A decision log: "Rex betrayed the crew because he was promised the pod."
TRACK 02

NPCs in disguise

✕ Agents that wait for the player to talk to them.
✓ Agents act on their own schedule. The world changes while humans are away.
TRACK 03

Vibes-only feedback

✕ "Great job! 8/10."
✓ Quote what the human said and tie every score to evidence from the session.
Starter toolkit

🧰 What people typically build with

Suggestions only. Use any stack you like. Also check what our sponsors offer.

🌍 Worlds & rendering

Three.js, Babylon.js, Unity, Unreal, Godot, Phaser. Blender or ready-made asset packs for characters.

🧠 Agent brains

Any LLM API with structured outputs or tool calls, plus a loop: observe → think → decide → act → log.

📚 Memory & learning

Reflection summaries, vector memory, relationship scores, RL (Gymnasium, ML-Agents) or fine-tuning.

🎙️ Voice & audio

Text-to-speech with a distinct voice per agent, speech-to-text for humans, generated music and SFX.

🌐 Multiplayer

WebSockets, Colyseus, Photon, Nakama, or any game server that lets agents join as players.

🎞️ Video output

Screen capture, Unity Recorder, Blender renders, ffmpeg for stitching your 1–3 minute short.
